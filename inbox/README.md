# Inbox

A low-friction capture space for anything that might matter later: thoughts, ideas, tasks, links, questions, problems, goals, or things to research.

## Rules

- **Capture first; organize later.** Do not stop to categorize or polish an entry.
- Use `INBOX.md` as the default dumping ground.
- For a large dump, create a separate dated file in this folder and link it below.
- Nothing in the inbox is automatically a commitment. Review and decide what deserves action.
- When processing an item, move it to the right place in Career OS or mark it as processed here.
