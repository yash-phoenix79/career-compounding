# Low-Level Design (LLD)

This section tracks the user's structured LLD capability programme and practical design exercises.

## Active programme

- [LLD Engineering Capability Programme](LLD_CAPABILITY_PROGRAM.md) — locked 8–10-week first-principles programme, 30 minutes per session, six sessions per week, Java, guided teaching, prerequisites, mastery gates and transfer assessment.

## Active challenge

- [Vending Machine — LLD Challenge 001](../exercises/vending-machine/README.md) — first end-to-end design and implementation exercise.

## Operating principles

- Learn prerequisites from first principles and test understanding.
- Derive designs from requirements; do not memorize standard diagrams.
- Produce evidence in every session.
- Use the challenge to practise thinking, modelling, designing, implementing, judging and defending.
- Track actual work in the root progress log.
